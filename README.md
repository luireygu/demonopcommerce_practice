# Demo NopCommerce – Automation Practice

🛒 **Automatización de Pruebas Funcionales para E-commerce (nopCommerce)**

Este proyecto contiene un conjunto de **pruebas automatizadas de interfaz web (UI)** para la aplicación de demostración **nopCommerce**, desarrollado como práctica profesional de **QA Automation** utilizando **Java, Selenium WebDriver y BDD con Cucumber (Gherkin)**.

El repositorio está diseñado como **proyecto de portafolio**, mostrando estructura, diseño y buenas prácticas aplicadas a un entorno real de e-commerce.

---

## 🎯 Objetivo del Proyecto

- Automatizar flujos críticos de un e-commerce
- Validar comportamiento funcional desde la perspectiva del usuario
- Aplicar **Page Object Model (POM)** y **BDD**
- Construir un framework base reutilizable
- Demostrar habilidades técnicas como QA Automation Engineer

---

## 🧠 Alcance de las Pruebas

Las pruebas cubren escenarios funcionales como:

✔ Navegación por el sitio  
✔ Login de usuario  
✔ Validación de formularios  
✔ Interacción con elementos web  
✔ Flujos básicos de usuario en una tienda online  

El objetivo no es cubrir toda la aplicación, sino **demostrar calidad en el diseño de pruebas**.

---

## 🛠 Tecnologías y Herramientas

| Tecnología | Uso |
|----------|-----|
| **Java** | Lenguaje principal |
| **Selenium WebDriver** | Automatización de UI |
| **Cucumber (BDD)** | Definición de escenarios en Gherkin |
| **JUnit / TestNG** | Ejecución de pruebas |
| **Gradle** | Gestión de dependencias |
| **Page Object Model** | Diseño del framework |
| **IntelliJ IDEA** | IDE recomendado |
